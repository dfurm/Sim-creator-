# Scientific and educational assurance

For each variant freeze source edition and equation locator, signs and units, independent/derived inputs, initial and boundary values, fit range, numerical error target, reference fixture and a short physical explanation. An equation or a matching spreadsheet does not validate equipment behaviour. Retain a reviewer separate from the implementer for scientific sign-off where feasible.

| Gate | Evidence and pass conditions | Failure action |
|---|---|---|
| Research concept → specification drafted | A–P complete at declared depth; outcome, planned data origin, visual mapping, missing data and scope explicit | Return to author with specific gaps |
| Mathematical model verified | Subject reviewer checks derivation, assumptions, physical dimensions; second-method benchmark, zero/limit/boundary cases; conservation, residual and refinement evidence | Quarantine variant or narrow documented scope |
| Prototype implemented | Frozen fixtures run through normal public block API in browser and worker where applicable, independently of this pack’s reference worksheet | Correct implementation or versioned fixture after documented review |
| Educational review completed | Academic and learners complete prediction, investigation and transfer on desktop/mobile and text-only equivalent; identify misleading visuals or feedback | Update educational wrapper independently; rerun affected tasks |
| Released educational simulation | Numerical and UI gates, accessibility and browser evidence, licence inventory, exact model/schema versions, rollback and archived scenario replay | No public release until open critical issues close |
| Experimentally validated for defined service | Held-out independent run(s), complete instruments/geometry/uncertainty, documented domain and acceptance limits, reviewer and date | Retain a verification-only claim or qualify domain |

**Tolerance policy.** For well-conditioned closed forms compare unrounded values to a high-precision independent result using |e|≤max(atol,rtol×|reference|), default rtol=10⁻⁸ and dimensioned atol set per output (1e−8 of a documented characteristic scale unless a stricter fixture exists). Printed examples have their own rounding tolerance in reference_checks.py. Bracketed solves require both residual and bracket/step criteria; scaled residual ≤1e−9 and relative width ≤1e−8 for normalised well-conditioned cases; limits have separate branches. Clamp floating-point roundoff only within a documented tolerance. Unreachable targets, rank failure and no bracket are expected return types. Require balance residual below 1e−8 of transported amount for closed analytic models. For numerical transients use a documented mesh/time study, e.g. relative change <0.5% in quantity of interest on successive independent refinements plus <0.1% normalised balance error as provisional tolerances. Tighten or justify per model; numerical agreement cannot eliminate model-form uncertainty.

**Tests that must survive an edit.** SI↔display round trip; no negative absolute temperature or absolute pressure; stagnation and zero driving force; equal capacities and equal terminal temperatures; sensible output as flow approaches zero; stationary marker and field linked to identical model revision; no stale result after worker cancellation; transition and unknown conditions on both sides; direct vs inverse round trip; compare a saved/pinned academic activity after an upgrade. Exercise touchscreen/keyboard, screen reader, missing external assets, unsupported variants, offline availability, malformed/unitless CSV and synthetic/measured origin. A tie or multiple inverse answers must remain visible.

**Physical validation protocol.** Define a prediction, service envelope and quantity-specific tolerance *before* collecting holdout data. Record instrument calibration/resolution, tap elevation and bore, replicates, units and time alignment. Separate calibration and validation by run/day/equipment condition as appropriate, never by adjacent rows from one run. Plot observed vs predicted with measurement bars, residual vs flow, time and other operating variables; report bias, RMSE, conditional uncertainty, number and coverage of independent runs. Account for covariance for quantities formed from shared instruments. A normalised residual using combined standard uncertainty is appropriate only when independence/covariance and uncertainty basis are justified. Assess practical impact on the target learning/design decision. Revalidate after geometry, sensor, curve, range or material-property changes. Simulation-only and synthetic runs cannot establish physical validation.

**Pack audit.** reference_checks.py is executable independent arithmetic for all 28 prototype topics. Its checked outputs are recorded in reference_results.json. These are spec checks using SciPy/NumPy or direct identities. They do not represent tests of a browser product, human peer review or rig validation. Variant-specific acceptance includes the limiting and invalid cases in each controlled brief. Archive original source, method and tolerance whenever a fixture changes.
