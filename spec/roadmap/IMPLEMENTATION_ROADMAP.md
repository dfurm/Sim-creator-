# Phased implementation and acceptance

Relative effort uses small (1), medium (2–3) and large (4–5) block estimates, assuming reusable UI and model tools exist. Effort points compare work; do not convert to a fixed delivery date before the shared kernel and two representative blocks have shipped. Scientific and educational review is additional to coding. The numerical priority score is evidence for selection, not a sequence that can ignore prerequisites.

| Track | Recommended sequence | Entry / exit condition | Dominant risk |
|---|---|---|---|
| Initial website | Versioned shell, unit/validity engine, state plus graph/scene; vertical slice S11 wall and S02 continuity; add S03, S07, S04, S05, S08 and S09 along the hydraulic path | Exit when both vertical slices work offline/standalone and embedded, saved predictions replay, unsupported regimes suppress affected estimates and a lecturer completes a keyboard-only exercise. Add comparator modules after base gates. | Distributed state or misleading diagrams; compare equation, graph and export from one calculation revision. |
| Expanded undergraduate | S01 early authoring companion; S26/18 then S21/19/20; S06/14, S13/17, S15, S22/23; S33–63 and other subject blocks by semester demand | Each block passes analytical/solver, applicability, curriculum and device gates. Pilot a transfer problem outside the first example before scaling authoring effort. | Numerical breadth outruns review capacity; reuse mechanisms and release small subject packs. |
| Equipment design | S10 after S08/09, then S12, S16, S20, S23, S24; S47, S60, S63, S65, S75/76/79 as data mature | Each design has independent basis, forward/inverse checks, at least one infeasible case, explicit equipment limits and trade-off table. | False precision in selection and costs; identify required vendor confirmation. |
| Advanced numerical | S26 and regression/uncertainty S27/28; S32 then S58, S66/68, S77; add workers/WASM only after profiling | Manufactured/analytic references, mesh and timestep evidence and stable replay; profile worst allowed case on target device. | Solver failure or false complexity; test near singular/branch transitions. |
| Experimental integration | S09/S08 first on EXP01/02, S45 on EXP03, S25 on EXP04. Later passive tracer S19/57 and heat exchange with correct bath basis | Independent measurement, documented sensor units/timebase, held-out service window, uncertainty and correction history. | Uncertain geometry or confounded calibration; retain unknown status when evidence is missing. |
| Recipe Lab and LMS | Prove block init/restore/lock/anchor events from a mock host now. Later add Recipe Lab editor/adapters, scoped Qt/lectures and LMS commitments. | One immutable model serves two lessons with different hidden variables and evaluation; feature compatibility and migration tested with old recipes. | Coupling lessons to physical screen positions or a single equipment profile. |

**First delivery gate.** S11 proves the term-to-material interaction, discontinuous interface temperature and independent sizing exercise without relying on hardware data. S02 proves SI conversions, constrained controls and an independent second physical scene. S09 demonstrates commercial relevance once hydraulic prerequisites exist. These also give three different failure classes (interface physics, inconsistent inputs, no operating point). Keep authoring manual until authors repeat the same activity enough times to justify tooling.

**Indicative shared effort.** Discovery and reviewed contracts 3–5 shared points; kernel/units/validity 5–8; accessible diagram, graph and math components 5–8; embed/offline/snapshot 3–5; CSV with data lineage 3–5; independent QA fixtures and browser matrix 3–5. These are scope-relative estimates, not prices or staffed sprints. Re-estimate against actual effort after S11/S02 and a single WP staging deployment.
