# Provisional decisions

| ID | Decision and reason | Authority or revisit condition |
|---|---|---|
| D01 | One external static web runtime, WordPress embeds it. Keeps hosting simple and portable. | Furmtech approves production origin, hosting budget and support window. |
| D02 | Use a shared science kernel and independently versioned lesson scenarios. Allows one model to teach multiple activities or run without recipe. | Confirm exact adapter with Author/Master/Recipe Lab owners. |
| D03 | No sign-in, telemetry or grade service in first release. Local state export is sufficient for formative work. | University identity, retention and passback require institutional agreement. |
| D04 | Group coverage into 84 independently versioned blocks with named modes. The 28 specified prototypes each retain an independent ID. | Split when independent inputs, boundary conditions or review ownership demand it. |
| D05 | Start with Fourier wall and continuity, then build pump chain; rank weights are product judgements. | Furmtech/academic panel can change weights and constraints and re-score without renumbering blocks. |
| D06 | Synthetic teaching curves and property constants first; vendor/real-data deployments require provenance. | Academic and equipment owner clear individual models, data and redistribution. |
| D07 | All host commands limited to educational simulation. Desktop operating authority remains separate. | Physical integration is a separate design and safety review. |
| D08 | Original content/diagrams by default; no third-party simulation or dataset embedded in this pack. | Rights owner approves specific reuse; select product code/content licence before distributing authored sources. |
