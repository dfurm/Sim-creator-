# Project scope and deliverable map

Furmtech Chemical Engineering Interactive Simulation Library · specification baseline 0.1.0 · 25 November 2026.

The first public product is an independent educational website collection. A simulation block owns its scientific model and state. Learning activities choose what to reveal and assess. Furmtech Author continues to configure equipment; Master operates it; Master Simulation provides virtual environments; Recipe Lab can later sequence and overlay educational blocks. A physical rig is optional for learning and essential for claims about that rig’s behaviour.
