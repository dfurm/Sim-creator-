# Recipe Lab, Master and FlexBench

A .furm equipment profile describes equipment and tag configuration. Proposed independently versioned educational recipes may point to the same profile and the same simulation model. Academic content selects restrictions, scenario and evidence requirements. The block never imports an Author project or assumes an attached PLC. Introduce a mapping adapter only when the relevant profile, channel and unit conventions have been inspected in the actual software.

| Host | Inputs and ownership | Evidence / completion |
|---|---|---|
| Website | Default scenario and selected model variant. Anonymous, browser-local state. | Optional CSV/state export. A lecture can be unguided. |
| Recipe Lab | Exact simulation and scenario version, visible/hidden/locked controls and outputs, narrower bounds, prediction prompt, scenario events and overlay target IDs. | Predicate tree with explicit units, tolerances, duration or explanation evidence. Resume by exact state/version; an author can choose no assessment. |
| Master Simulation | Simulation-only input mapping, declared engineering units, simulated time, run/source flags. Master keeps process-operation ownership. | Compare virtual traces against the same educational model; never mistake synthetic tags for a physical run. |
| Master + FlexBench | Read-only archived CSV first. Future adapter resolves approved semantic channels from a .furm profile and device metadata. | Predicted pump duty vs measured duty, with time-window selection, instrument resolution, geometry, speed basis and uncertainty. |
| University LMS | Hosted iframe or course package; later opt-in SCORM, xAPI or LTI. | Only authorised completion/score events leave the page. Server-side verification is necessary for high-stakes grading. |

**Concrete pump path.** In EXP01 have the student predict head at two flows and save a curve with assumptions. In EXP02 show how a valve stroke changes system resistance; a loss coefficient is not identical to actuator position. In EXP03 select series or parallel and predict the installed duty. Compare to an independent physical run with aligned pump speed and valve setting. In EXP04 ask whether saturation, sensor lag or plant response explains the trace. A pump command percentage is not RPM or measured shaft power.

Use CSV channels time_s, flow_m3_s, p_suction_Pa and p_discharge_Pa as proposed canonical names; actual headers require a mapping preview. Declare absolute/gauge reference, time zone or monotonic origin, sensor tap heights, actual inside diameters, density and speed. Compute measured head H=(pd−ps)/(ρg)+(vd²−vs²)/(2g)+zd−zs. Gauge readings using the same reference may be differenced. Differently referenced gauges need correction. Reject missing units and unlabelled timestamps; retain excluded points and reasons. Never infer pump efficiency from speed command. Compare EXP01 fit against different runs, not rows withheld from the same quasi-steady window.

**Anchors and overlays.** Each block publishes logical IDs, role, label and optional repeatable entity ID; e.g., S11/material_layer_1, S06/boundary_layer_profile, S09/pump_operating_point. Resolve to current SVG/DOM node or accessible equivalent at render time. On mobile a collapsed graph can return an affordance to reveal it. Rename only with migration alias. Missing required anchors block scenario launch with diagnostic; optional ones fall back to their textual description. Overlay highlight is reversible, keyboard-focusable and scoped to the instance.

**Privacy and interoperability.** Anonymous starter state omits name, email, LMS identifiers and device tracking. Save locally only on explicit action, permit export/delete, explain that browser storage can be cleared. Import teaching data with local processing; inspect and remove identifying free text. University integration requires data minimisation, explicitly authorised purposes, access controls, retention period, hosting location, deletion and institutional privacy review [PRIV]. For H5P the outer package licence and each asset licence are recorded independently. A static iframe alone does not grant identity, score submission or access to cross-origin H5P events.
