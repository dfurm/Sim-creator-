# S07 · Reynolds number and competing scales

## A · Identification

S07 · specification 0.1.0 · Fluids · primary category B · Introductory · F1 · effort 2/5 · 8–15 min. Maturity: specification drafted. Prototype implementation brief.

## B · Educational purpose

Hold velocity constant and double diameter, then repeat holding Q constant. Predict the opposite changes in Re and identify the variable the equipment actually holds.

Switching the controlled variable reverses the apparent diameter effect on the same Reynolds number.

Outcome: Choose D for a target Re under each constraint. Transfer to a stirred tank and identify the new characteristic velocity/length before using any correlation. Prerequisites: No additional block required. Understand / Apply. Lecture demo, tutorial, guided or independent web activity, pre/post-lab. Practice link: EXP01/02 pipe geometry, flow and viscosity. Industrial teaching context: Piping, pumping and metering.

## C · Mathematical basis

Re=ρvD/μ=vD/ν; constant-Q mode derives v=4Q/(πD²). Default prescribed-speed mode. For external flow replace D with distance from the leading edge and use free-stream U.

Independent quantities and engineering units appear below. Outputs are derived. Assume SI absolute state variables unless a quantity is explicitly a difference or a gauge reading. Algebraic variants use the listed boundary state and require no time initialisation.

## I · Assumptions and applicability

Pipe screen Re<2300, 2300–4000 transitional, >4000 commonly turbulent for developed Newtonian flow; disturbance can alter onset. Thresholds belong to geometry, never reuse pipe labels for plates, impellers or beds.

Apply per-output within/approaching/outside/unknown rules. Record assumed facts separately from verified input evidence. Unmodelled physical states or invalid dimensions suppress the corresponding output.

## L · Learning activities

**Explore.** Hold velocity constant and double diameter, then repeat holding Q constant. Predict the opposite changes in Re and identify the variable the equipment actually holds.

**Investigate.** Commit a prediction before changing a control. When diameter doubles, choose what the pump holds. Students who answer “Re doubles” before identifying the constraint have insufficient information.

**Challenge and assessment.** Choose D for a target Re under each constraint. Transfer to a stirred tank and identify the new characteristic velocity/length before using any correlation. Submit a result with units, one rejected interpretation and the condition that would change the answer.
