## C · Mathematical basis

From target Q̇ calculate terminal temperatures using Ch,Cc. For counterflow ΔT₁=Thi−Tco, ΔT₂=Tho−Tci; for parallel use inlet and outlet differences. ΔTlm=(ΔT₁−ΔT₂)/ln(ΔT₁/ΔT₂), limit ΔT₁=ΔT₂. A=Q̇/(Udirty ΔTlm); 1/Udirty=1/Uclean+Rf″.

Independent quantities and engineering units appear below. Outputs are derived. Assume SI absolute state variables unless a quantity is explicitly a difference or a gauge reading. Algebraic variants use the listed boundary state and require no time initialisation.

## I · Assumptions and applicability

Ideal two-stream single-phase exchanger only. Positive approaches required; 0 duty → 0 area, limiting duty requires infinite area. Shell-and-tube correction factors require a separately specified geometry; Δp, vibration, allowable pressure and fouling service need vendor work.

Apply per-output within/approaching/outside/unknown rules. Record assumed facts separately from verified input evidence. Unmodelled physical states or invalid dimensions suppress the corresponding output.
