## C · Mathematical basis

Hₚ=s²H₀−aQ²; Hs=Hz+bQ²; Q*=√[(s²H₀−Hz)/(a+b)] when numerator positive. Shaft power=ρgQH/η only with specified efficiency. Synthetic centrifugal curve; Q in m³/s. g=9.80665, ρ=1000.

Independent quantities and engineering units appear below. Outputs are derived. Assume SI absolute state variables unless a quantity is explicitly a difference or a gauge reading. Algebraic variants use the listed boundary state and require no time initialisation.

## I · Assumptions and applicability

Illustrative quadratic curves, similar hydraulic operation. Limit to forward flow and Hₚ≥0; no positive duty if shutoff ≤ lift. Real power/efficiency, allowable flow, motor limits and NPSH need independent vendor curves. Same-speed measured data do not validate affinity extrapolation.

Apply per-output within/approaching/outside/unknown rules. Record assumed facts separately from verified input evidence. Unmodelled physical states or invalid dimensions suppress the corresponding output.

## L · Learning activities

**Explore.** Throttle a valve and follow the intersection of pump and system curves. Ask whether a speed command fixes the flow.

**Investigate.** Commit a prediction before changing a control. Close the valve at fixed speed. System curve steepens and duty moves up and left. The original pump curve remains valid within its measured speed range.

**Challenge and assessment.** Choose speed and restriction for a required flow, then compare input power; hydraulic throttling trades off against delivered head. Compare EXP01 pump data and EXP02 resistance. Submit a result with units, one rejected interpretation and the condition that would change the answer.
